# 生存沙盒游戏 — 初步设计文档

## 1. 核心概念

一款以**寻找走散的朋友**为长期目标，以**生存**为短期目标的 2D 生存沙盒游戏。

- 长期目标：寻找其余走散的朋友。
- 短期目标：收集资源、探索世界、建造设施，保证生存。
- 核心体验：生存、探索、陪伴与伙伴互动。
- 整体方向：以生态探索和旅途体验为核心，而非以战斗和死亡为核心。

## 2. 角色与伙伴系统

- 游戏中共有 **5 名朋友**。
- 玩家在开局时选择其中一人，作为自己扮演的角色。
- 其余朋友通过探索逐步寻找。
- 找到的朋友采用自主 NPC Agent 框架实现，而不是单纯作为装备或属性强化。
- Agent 负责伙伴的自主行为与交互。
- 伙伴系统强调独立人格、互动和陪伴感。

## 3. 交互与对话

朋友之间的对话采用类似 Galgame 的线性对话形式：

- 线性推进的对话。
- 带边框的对话框。
- 重点体现角色之间的交流与陪伴感。
- 剧情、角色设定与背景故事由开发者负责创作。

## 4. 生存模式与世界探索

采用类似《泰拉瑞亚》的 **2D 侧面视角**。

设计考虑：

- 降低空间维度，简化世界与角色的空间交互。
- 强化横向探索，让玩家主动前往地图两侧。
- 将探索、资源收集与寻找朋友结合。
- 生存玩法作为玩家持续探索的基础。
- 保留一定的垂直探索空间，尤其是地下区域。

### 4.1 地表环境

参考《雨世界》的环境与生态设计理念：

- 强调天气、地形、昼夜和自然环境。
- 环境本身具有变化与规律，不完全围绕玩家运转。
- 生物拥有自己的活动规律与生态关系。
- 风雪、温度、地形等因素影响玩家的旅行。
- 环境探索和生态观察是重要的游戏体验。

### 4.2 地下探索

保留成熟的 2D 沙盒地下探索模式，但需要设计具有独立特色的地下场景。

可能包含：

- 冰层洞穴、地下森林、地下湖泊。
- 深层洞窟与特殊生态区域。
- 地下遗迹及旧文明设施。
- 矿物、特殊材料和隐藏资源。

地下不仅是获取矿物的场所，也应当具有独立的环境、生态和探索价值。

设计原则：

- 地表负责体现世界的辽阔。
- 地下负责体现世界的深度。
- 兼顾程序生成与人工设计，保证地图的丰富度和探索体验。

### 4.3 生存压力

降低怪物和死亡在游戏中的权重。

生存压力更多来自自然环境与旅行过程：

- 风雪与低温。
- 食物、燃料等资源管理。
- 夜晚与照明。
- 地形和天气对路线的影响。
- 旅行过程中的风险与意外。

死亡不应成为主要的探索惩罚，重点是让玩家体验旅行、探索和生活。

### 4.4 居住与交通

不强制玩家建立固定的永久住所。

考虑以下设计：

- 临时营地：篝火、帐篷、储物设施等。
- 自然避难所：洞穴、废弃建筑等。
- 可利用的安全地点。
- 类似《原神》的传送锚点，作为已经探索区域的交通节点。

建造不只是扩大基地规模，也可以服务于旅行和生活。

### 4.5 世界路线

考虑采用环形或具有回环结构的探索路线：

- 玩家从初始地点出发。
- 向不同方向探索并寻找朋友。
- 逐步了解世界与生态。
- 最终有机会完成环绕探索，回到最初的地点。

希望让玩家再次经过熟悉地点时，因为伙伴的重聚而获得不同的情感体验。

## 5. 资源、材料与制作

矿物和材料系统予以保留，并允许持续拓展。

材料主要分为三个方向：

| 类型 | 主要用途 |
|---|---|
| 功能性材料 | 工具、照明、保暖、设备、交通 |
| 建造材料 | 营地、避难所、家具、设施 |
| 装饰性材料 | 家具、墙面、地板、摆件及外观装饰 |

设计原则：

- 材料应当具有明确用途。
- 不单纯通过增加矿物数量延长游戏时间。
- 稀有度不应是材料价值的唯一标准。
- 制作系统应当解锁新的探索能力与生活方式。
- 装饰系统允许玩家表达个性，并让临时住所具有生活气息。

## 6. 音乐与声音设计

音乐是游戏的重要组成部分，不只是背景音。

设计方向：

- 不同生态区域拥有不同的音乐氛围。
- 天气、昼夜和场景可以影响音乐表现。
- 角色可以拥有自己的主题旋律。
- 考虑通过旋律变奏表现角色关系与剧情变化。
- 环境音与音乐共同塑造世界的氛围。

### 6.1 Agent 辅助音乐生产

可以利用 Agent 辅助音乐内容创作：

- 主题与旋律构思。
- 和声与配器。
- 场景音乐制作。
- 角色主题音乐。
- 音乐变奏与环境音设计。

生产流程采用 Agent 辅助创作、人工审核与修改的方式，建立原创音乐资产库。

需要注意生成工具的商用许可、素材来源及版权授权。

## 7. 美术与视觉风格

整体采用 2D 像素艺术风格，参考《泰拉瑞亚》的侧面场景结构与《雨世界》的环境表达。

### 7.1 核心视觉方向

- 低饱和度的环境色彩。
- 细腻的环境光照与冷暖对比。
- 环境占据较大的视觉比例。
- 人物是画面的情感中心，世界是画面的主体。
- 强调天气、风雪、植被和环境动态。

## 8. 游戏专用 Skills

在正式搭建游戏框架和批量生产内容之前，建立项目专用 Skills(我们需要同时进行游戏制作与skills完善)。

目的：使不同 Agent 在参与开发和内容生产时，遵循统一的设计与质量标准。

初步规划：

| Skill | 主要职责 |
|---|---|
| Pixel Art Skill | 像素尺寸、调色板、描边、光照、角色比例与动画规范 |
| Environment Art Skill | 地表、地下、天气、地形、生态区域与视差背景 |
| Item & Material Skill | 矿物、工具、家具、装饰和物品贴图 |
| Music & Sound Skill | 场景音乐、角色主题、动态变奏与环境音 |
| UI & Dialogue Skill | Galgame 式对话框、菜单、背包与交互反馈 |
| Lore Integration Skill | 读取开发者提供的世界观、背景故事和角色设定，保证内容一致性 |

### 8.1 Skill 设计原则

- Skills 不只是内容生成提示词，还应当包含明确的质量标准。
- 不同 Agent 生产的内容必须保持风格一致。
- 重要角色、场景和音乐需要人工审核。
- 先制作小规模测试资产，验证规范，再进行批量生产。
- 世界观、背景故事和核心剧情由开发者掌握决定权。

## 9. 联机与技术方向

希望游戏未来支持多人联机。

需要在架构设计时考虑：

- 玩家角色与自主 Agent 的协同。
- 多人环境下角色状态和世界状态的一致性。
- Agent 在联机环境中的行为与控制权管理。
- NPC 自主行动与玩家直接控制之间的协调。

技术设计需要为后续联机保留空间，而不是等单机完成后再简单添加联机功能。

## 10. 当前设计定位

本项目并非简单复刻已有生存沙盒游戏，而是在经典生存、探索玩法的基础上，进一步强调：

- 环境与生态。
- 旅途与探索。
- 伙伴关系与陪伴。
- 丰富的材料、制作和装饰。
- 音乐与视觉氛围。
- 自主 NPC Agent。

**核心设计理念：**

生存提供继续前进的理由，寻找朋友提供持续前进的目标，伙伴系统让世界拥有陪伴感。

**视觉与情感理念：**

不是为了在这个世界里活下来而建造一个家，而是为了继续旅行，逐渐让这个世界成为自己的家。

**成长理念：**

成长不只意味着角色变强，也意味着玩家逐渐拥有更丰富的生活方式。
