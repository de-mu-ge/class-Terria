# 第二轮 · 序章实现提示词

> 用法：把本文件全文贴进下一轮对话，作为本轮的 User 提示词。
> 本文件只规定**怎么实现**；剧情内容以 `第一轮剧情.md` 为准，不得改写。

---

## 一、本轮目标

把 `第一轮剧情.md` 里的序章 Scene 01–07，做成一条**可以从头玩到尾的可运行流程**：

开始界面 → Scene 01 → 02 → 03 → 04 → 05 → 06 → 07 → 控制权交接 → 进入待开发的生存模式占位画面。

要求：能跑、能推进、不卡死、退出不报错。不要求做完所有美术，不要求做玩法和存档。

## 三、技术基线

- 语言 Python，Conda 环境 `game`（`conda activate game`），缺依赖自行安装。
- 渲染引擎 **pygame-ce**；但渲染必须收敛到 `Renderer` 抽象类，将来可换引擎。
- 逻辑分辨率 **960 × 540**，窗口按 2× 显示（1920×1080），整数倍缩放，禁止平滑拉伸。
- 帧率 60，固定时间步长更新；对话打字机按字符计时，不按帧。
- 所有坐标、颜色、时长、文本全部外置到配置/数据文件，**代码里不得出现剧情台词**。

## 四、工程约束

沿用第一轮要求：面向对象、接口/封装、低耦合、参数外置、为联机预留。

本轮至少落地这些结构：

```
src/
  core/        引擎无关层：GameLoop、SceneStack、StateMachine、ResourceManager
  scenes/      每个 Scene 一个类，实现 enter/update/handle_event/exit
  ui/          对话框、名字条、菜单、字幕、过场遮罩
  render/      Renderer 抽象 + PygameRenderer
  data/        scenes.json、dialogues.json、characters.json（文本与数值）
  assets/      资源路径解析（只读，不写）
```

规则：

1. `Scenes` 之间只通过 SceneStack 切换，禁止直接互相引用。
2. 台词、镜头指令、演出时长一律读 `data/*.json`。
3. 每个 Scene 必须支持单独启动调试：`python -m src --scene 03`。
4. 任何资源缺失必须有占位方案，不得崩溃。

## 五、序章实现规格

剧情文本、台词、镜头顺序**严格照 `第一轮剧情.md`**，本节只补工程口径。

| Scene | 舞台 | 视觉段落 | 现有可用背景 | 需要补的 |
|---|---|---|---|---|
| 01 春日的集合 | 樱花广场 | 现实（动画背景+立绘） | `视觉稿/序章_v1/02_scene01_plaza.jpg` | 手机群聊 UI |
| 02 五个人的集合 | 同一广场 | 现实 | 同上（建议裁切中景） | 五人站位与表情差分 |
| 03 出发前往英国 | 港口 | 现实 | `03_scene03_port.jpg` | 登船过场 |
| 04 海上的旅行 | 客轮甲板 | 现实 | `04_scene04_deck.jpg` | 合照定格与照片界面 |
| 05 异常天气 | 甲板→船舱 | 现实 | `05_scene05_storm.jpg` | 摇晃、灯光闪烁、广播音 |

| 07 直到再次相遇 | 像素海岸 | 未知世界（像素） | `p1_coast_wakeup.jpg`、`py1_coast_slice.png` | 像素 Sprite、HUD、任务提示 |

背景图放 `assets/backgrounds/prologue/`，按 Scene 编号命名（`s01_plaza.png` 这种）。

### 5.2 逐 Scene 的硬要求

**Scene 01**：黑屏淡入 → 天空 → 樱花 → 镜头下移 → 爱音入画 → 立绘 → 对话框。手机群聊必须是独立 UI 层（三条消息依次出现，带提示音），不是画在背景里。

**Scene 02**：五人站位必须与文档一致，不允许无动作说明就换位置。对话至少覆盖文档列出的全部台词，不得删句。

**Scene 03**：港口 → 登船通道 → 客轮离港。只有一头一尾两个镜头即可，中间用淡出。

**Scene 04**：甲板对话 → 合照流程 → 照片定格 2 秒。照片界面用一个静态构图 + 快门音，不要求真的合成图片。

**Scene 05**：天气由晴转阴用**渐变遮罩**实现（不是换图）；船体摇晃用画面整体位移 2–3px、频率 0.5Hz；广播用字幕条 + 环境音；通讯异常时右上角信号图标变成无信号。

**Scene 06**：雾中岛屿分三段推近（远山剪影 → 森林轮廓 → 山峰），每段 1.5 秒；随后强晃 → 闪白 0.15s → 黑屏 2 秒。**此处必须切换渲染管线**：之前用动画背景 + 立绘，之后用像素场景 + Sprite。

**Scene 07**：黑屏 3 秒（海浪声先入）→ 像素海岸淡入 → 爱音 Sprite 倒地 → 呼吸 → 睁眼 → 坐起 → 站起 → 环顾 → 呼喊 → 立绘对话框收回 → 操作提示 → 交接控制权 → 显示初始任务。

### 5.3 对话系统

数据结构（示例，字段名可调整）：

```json
{
  "scene": "s01",
  "lines": [
    {
      "speaker": "anon",
      "portrait": "anon_normal",
      "emotion": "sleepy",
      "text": "好困啊……爽世究竟怎么想的啊，为什么一定要去英国演出啊！",
      "camera": "push_in",
      "sfx": null,
      "wait": 0.0
    }
  ]
}
```

要求：文本框、名字条、打字机、点击继续、跳过整段（按住 Ctrl 快进）、已读记录（本轮可只存内存）。

### 5.4 输入与流程

- 左键 / 空格 / 回车：推进对话。
- Esc：返回开始界面（二次确认）。
- 开始界面：开始游戏 / 继续（本轮禁用，置灰）/ 设置（本轮只有音量） / 退出。

## 六、人物方案：先用纸片

**本轮不画角色，一律用纸片（现成图）。**

| 类别 | 要求 |
