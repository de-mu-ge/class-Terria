# 游戏专用 Skills · 索引

路径：`提示词工程部分/游戏专用skills/`

本目录存放项目专属的制作规范与工具。每个 Skill 一个子目录，目录内至少有一个 `SKILL.md`，
写明：这个 Skill 解决什么、怎么做、质量标准、禁止项。

## 当前已建立

| Skill | 路径 | 状态 | 负责范围 |
|---|---|---|---|
| 视觉生图 | `视觉生图/` | v0.1 可用 | 参考稿生成工具链、提示词结构与风格预设 |
| 整体风格与 UI | `整体风格与UI/` | v1.0 已定路线 | 画风路线、调色板、像素规范、Galgame 对话框、HUD、开始界面、转场 |
| 角色设定 | `角色设定/` | v1.0 | 角色官方数据与配色、姿态基线、CC0 素材接入流程、场景融合、版权边界 |

## 约定

1. 新增 Skill 时，必须同步更新本索引与 `操作提示词/系统提示词.md` 的技能路径表。
2. Skill 内容随开发进度逐步完善，**允许先立骨架再补细节**，但骨架必须写明质量红线。
3. 任何视觉资产进入游戏前，必须经过「规范 → 参考稿 → 人工敲定 → 落地」四步。
