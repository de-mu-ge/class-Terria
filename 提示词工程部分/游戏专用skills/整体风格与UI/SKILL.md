# Skill：整体风格与 UI（Style & UI）

> 版本 v1.0 · 位置：`提示词工程部分/游戏专用skills/整体风格与UI/`
> 本文件是**规范**，不是描述。做 UI、立绘、场景、动画前先读，产出必须能对照条目逐项检查。
> **本目录不放任何图片**。所有示意稿存 `提示词工程部分/视觉稿/`，本文件只用文字描述。

## 0. 已定路线（v1.0，2026-10-31 定）

**主题画风：2D 横版、高精度硬像素，网格基准对齐《泰拉瑞亚》（16 × 16 px / tile）。**

这条路线基于开发者原话「主题画风是 2D 横板像素画风，精度比较高的 Terraria」。

由此推出三条不可违反的推论：

1. **一切落在 16px 网格上**。禁止非整数缩放、禁止半像素、禁止镜头亚像素抖动。
2. **细节靠色阶和形状堆，不靠平滑渐变**。单屏内可用色数上限约 24 色（环境 16 + 暖色 4 + UI 4）。
3. **模型生图降级为「构图与配色参考」**，不作为游戏资产；资产一律按本规范重绘。

> 参考稿里那种「低分辨率厚涂」观感（笔触、柔和过渡）**不采用**。它的像素是降采样产生的假像素，
> 无法切图、无法排版到网格、无法复用调色板。

### 0.1 已结案的待定项

| 项 | 结论 |
|---|---|
| 逻辑分辨率 | **960 × 540**（整数倍放大，1080p 用 2×） |
| 对话框宽度 | 左右各留 24px，不贴边 |
| 像素字体 | 中文用 **Zpix**，英文数字同字体；现实段落另用思源黑体（非像素） |
| 对话框边框 | **暖金 `#C9A227`**，1px 外框 + 1px 内暗边 |
| 现实世界画风 | **清透日式动画背景**（樱粉 / 浅蓝 / 米白），不加水墨、不做胶片颗粒 |

以上属**默认值**，不是教条；要改必须写明改动理由与新数值，并同步本表。

## 1. 视觉定位

- 一句话：**低饱和冷色的广阔环境里，人物是唯一的一点暖光。**
- 参考坐标：《雨世界》的环境与生态表达 + 《泰拉瑞亚》的 2D 侧面结构 + Galgame 的演出节奏。
- 原则：环境是画面主体，人物是情感中心；不追求华丽堆料，追求层次和可读性。
- 序章特殊性：前段是「动画感」的现实世界，后段是「像素感」的未知世界，两者必须能无缝接住。

## 2. 双视觉阶段（序章）

| | 现实世界（Scene 01–06 前半） | 未知世界（Scene 06 后半–07 及全部玩法） |
|---|---|---|
| 背景 | 2D 日式动画背景，有渐变与细节 | 2D 像素，块面清晰，16-bit |
| 人物 | Galgame 立绘，表情可切换 | 游戏 Sprite，侧面视角 |
| 镜头 | 推、拉、横移、切 | 固定侧面视角，仅水平跟随 |
| 色彩 | 明亮温暖：粉 / 浅蓝 / 米白 | 低饱和冷色：深蓝 / 灰 / 雪白 |
| 声音 | 日常音乐为主 | 环境音为主，音乐退后 |

**切换点唯一**：Scene 06 的「画面闪白 → 迅速变黑」处。此前不允许出现像素，此后不允许出现立绘。

## 3. 像素规范

| 项 | 规定 |
|---|---|
| 逻辑分辨率 | 960 × 540（16:9） |
| 放大方式 | 只允许整数倍（1080p 用 2×），禁止非整数缩放 |
| 基础网格 | 16 × 16 px = 1 tile |
| 角色 Sprite | 32 × 64 px（与占位素材一致），脚底对齐网格；动画帧数以素材为准，至少含待机 / 行走 / 跳跃 |
| 描边 | 角色外轮廓 1px 深色描边（不纯黑），内部不使用描边 |
| 光照 | 统一左上主光源；禁止写实渐变，用 3–4 级色阶过渡 |
| 禁项 | 半像素坐标、非整数缩放、模糊/抗锯齿、照片贴图、过饱和 |

## 5. Galgame 对话框

设计坐标系 960 × 540（运行时 ×2 放大）：

| 项 | 数值 |
|---|---|
| 面板范围 | x 36–924，y 393–516（高 123） |
| 内边距 | 左右 18，上 15，下 15 |
| 名字条 | 面板左上独立小块，180 × 39，y 363 起 |
| 边框 | 外 2px `#C9A227`，内 1px 半透明暗边，直角（不用圆角） |
| 文字 | 正文 18px 像素字体，行高 27，每行约 40 字 |
| 打字速度 | 40 字/秒；单击立即显示全文，再击进入下一句 |
| 位置硬约束 | 立绘脚底必须高于 y=393，不允许压住对话框 |

## 6. UI 规范

**开始界面**

- 构成：像素海岸概念背景 + 暗角 + 左侧标题区 + 菜单列。
- 菜单项：开始游戏 / 继续 / 设置 / 退出，垂直排列，行距 24。
- 选中态：文字前加「▸」，配 1px 暖金下划线；不使用发光光晕。
- 右下角放版本号（12px，次文字色）。

**游戏内 HUD（未知世界）**

- 左上：生命 / 体温两条横条，宽 96、高 6。
- 右上：时间 + 天气图标。
- 底部中央：快捷栏 8 格，单格 32 × 32，选中格上移 2px。
- 序章阶段不显示饥饿、不显示地图、不显示任务列表以外的面板。

**字体**

- 像素阶段：Zpix（最像素）或 Fusion Pixel，12px / 24px 两档。
- 现实阶段（Galgame）：思源黑体 Regular/Medium，中文不用衬线。
- 禁止混用：同一画面内不得同时出现两种字体家族。

## 7. 转场与演出

| 场景 | 时长 | 做法 |
|---|---|---|
| 淡入 | 0.6s | 纯黑 → 画面 |
| 淡出 | 0.5s | 画面 → 纯黑 |
| 闪白 | 0.15s | 白场闪一次，然后切黑 |
| 镜头推近 | 0.8s | 缩放 1.0 → 1.15，缓出 |
| 场景切换 | 0.4s | 交叉淡化，不加转场花纹 |

禁止：旋转、翻页、马赛克、故障闪烁等花哨转场。

## 8. 序章专属约束

1. 现实世界不得出现任何像素元素（包括 UI）。
2. 未知世界不得出现任何立绘或动画渐变背景。
3. 开始界面属于「游戏外」，统一用像素语言。
4. 所有文字都不放进生图，全部由 UI 层渲染。
